# 产品规格

## 定位

Model Observatory 是面向模型 API 使用者的持续观测与证据平台。它比较官方 API 和第三方提供商在不同账号、节点、地区、时间与请求模式下的行为差异。

产品输出是“观测结论和置信边界”，不是模型身份的密码学证明。

## 用户角色

- 访客：查看公开 Dashboard、方法、证据覆盖与历史。
- 检测用户：使用自己的临时 key 运行私有检测并下载报告。
- 捐赠者：提供额度、受限 key 或执行节点，并随时撤销。
- 贡献者：提交模型版本、探针、概率基线和评分规则变更。
- 审核者：复现证据、处理冲突、批准 beta/stable 或撤销版本。
- 维护者：管理签名发布、权限、紧急停用和审计日志。

## 页面

| 路由 | 用途 |
| --- | --- |
| `/` | Dashboard 与风险概览 |
| `/providers/:slug` | 提供商证据、覆盖和历史 |
| `/private` | 普通/Native 私有检测 |
| `/donate` | 凭据、额度与节点捐赠和撤销 |
| `/registry` | 社区维护的模型数据库 |
| `/contribute` | Wiki 式字段变更与证据提交 |
| `/review` | 待审核变更与复现状态 |
| `/methodology` | 方法、信任分层和安全说明 |

## 首页指标

- 活跃提供商和模型数量。
- 最近 24 小时正式审计任务。
- 需要复核的路由差异和基线过期项。
- 每个提供商的正式证据、可信社区、匿名和自报样本数量。
- 账号、节点、地区、ASN、时间和基线版本覆盖。

## 非目标

- 不承诺识别所有代理、蒸馏、量化、缓存或选择性路由行为。
- 不公开捐赠密钥、完整指纹、原始敏感响应或可识别捐赠者的信息。
- 不用匿名票数决定正式结论。
- 不把单次检测结果当作永久评级。
